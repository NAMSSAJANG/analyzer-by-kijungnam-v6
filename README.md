# Stock Analyzer V6

Multi-Lens Stock Setup & Decision System.

A Streamlit-based stock analysis tool featuring:

- Company Quality Analysis
- Quant & CAN SLIM Analysis
- Pullback / Momentum Entry
- Market Regime Analysis
- Options Analysis
- Risk & Support / Resistance
- Setup Scanner
- Score History & Calibration

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
